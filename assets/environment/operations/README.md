Retrieved 11 October 2026 from the official 1K glTF download.

`tools/fetch_operations_light.py` verifies official MD5 hashes and embeds unchanged
mesh buffers and JPEG maps into one GLB. Exact URLs and SHA-256 hashes are recorded
in provenance.json. Existing Git LFS rules cover the GLB. No runtime downloads.

The command console, screen mount, cable looms, rack casing and power-up icons are
original project geometry/vector artwork. Console tabletop props reuse the existing
CC0 workstation assets. Rendered integration and human acceptance are separate.
