# Party food (Kenney Food Kit 2.0, CC0)

Retrieved 11 October 2026 from `kenney.nl/assets/food-kit` (download
`kenney_food-kit.zip`, CC0 1.0, [LICENSE_kenney.txt](LICENSE_kenney.txt)); attribution
optional and given voluntarily. Downloaded with the creator's permission for the pantry
birthday.

Kevin's birthday spread: `pizza_box`, `pizza`, `cupcake`, `donut_sprinkles`, `soda_can`,
`soda_can_crushed`, `soda_bottle`. Files are renamed to snake_case and stored with Git
LFS. The kit's shared `Textures/colormap.png` palette is kept as `textures/colormap.png`;
the only change to the GLBs is that one image URI, lowercased to match (same byte
length, geometry and materials untouched). `tools/pantry_layout.py` places and scales
them; they have no collision.
