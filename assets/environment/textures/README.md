# Environment PBR textures (CC0)

Retrieved 10 October 2026 without an account. All are CC0 1.0 (public domain
dedication); attribution is not required and is given voluntarily. 1K JPG maps,
unmodified except for renaming; stored with Git LFS. Materials that use them are
generated by `tools/build_office.py` (triplanar, tinted to the after-hours palette).

| Folder | Source asset | Author / publisher | Used for |
| --- | --- | --- | --- |
| `carpet` | ambientCG Carpet012 (`ambientcg.com/view?id=Carpet012`) | ambientCG (Lennart Demes) | Office and meeting-wing floors |
| `brushed_metal` | ambientCG Metal009 | ambientCG | Desk legs, rails, racks, thresholds |
| `vault_floor` | ambientCG MetalPlates006 | ambientCG | Server corridor and vault floor |
| `ceiling_tile` | ambientCG OfficeCeiling001 | ambientCG | Meeting-wing ceiling |
| `painted_plaster` | Poly Haven "Painted Plaster Wall" (`polyhaven.com/a/painted_plaster_wall`) | Amal Kumar | Walls |
| `polished_concrete` | Poly Haven "Concrete Floor 02" | Rob Tuytel | Circulation spine, deck, ramp |
| `walnut_veneer` | Poly Haven "Wood Table 001" | Dimitrios Savva, Rico Cilliers | Desks, tables, credenza |

Maps per folder: `color`, `normal` (OpenGL convention), `roughness`, and `metalness`
where the source provides one. Import settings are explicit (VRAM compressed, mipmaps,
normal-map mode, roughness channel) so the editor never needs to re-detect usage.
