# Production vault environment

Source: https://polyhaven.com/a/power_box_01

Commercial use, modification and redistribution permitted; attribution optional.
Official 1K glTF data is checksum-verified and embedded unchanged in a GLB by
`tools/fetch_vault_power_box.py`; provenance.json records URLs and hashes.
Godot extracts the embedded JPEG maps beside the GLB during import; those textures
and their import sidecars are retained for reproducible imports.

The detailed server cabinets, cooling banks, structural ribs, cable trays, safety
markings, breakable equipment and arena architecture are original project geometry.
PBR materials reuse the existing documented CC0 texture library. Practical hanging
lights reuse Poly Haven's Caged Hanging Light recorded in ../operations/README.md.
