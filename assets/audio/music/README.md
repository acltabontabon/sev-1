# Music beds (original synthesis)

Generated 10 October 2026 by `tools/build_music.py`: deterministic oscillator, noise
and envelope synthesis written for SEV-1. No samples, loops, presets or third-party
material; redistributable original work. Mono 22.05 kHz WAV, seamless loops (whole
cycles per loop, periodic envelopes and filters), imported with forward looping.
Stored with Git LFS. Listening and mix acceptance is pending creator review.

| File | Length | Use |
| --- | --- | --- |
| `menu_pad.wav` | 32 s | Title desk: four slow ninth chords, a shimmer, the wall clock |
| `tension_bed.wav` | 16 s, 120 BPM | Incident: drone, muted D pulse, ticking hats, risers |
| `boss_pulse.wav` | 8 s, 150 BPM | The Variance: thump, distorted ostinato, off-beat alarm |
| `mourning.wav` | 32 s, not looped | The walk out after Incident 001: slow minor pads, a falling bell-like line, a hall echo |

Playback uses the `Music` bus, which a sidechain compressor ducks under the `Voice` bus.
