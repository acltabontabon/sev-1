# Interface typefaces

Retrieved 10 October 2026 from the official Google Fonts repository
(`https://github.com/google/fonts/tree/main/ofl/…`). Files are unmodified; only the
file names were changed to the project's snake_case convention. Stored with Git LFS.

| File | Family / source path | License |
| --- | --- | --- |
| `barlow_condensed_bold.ttf`, `_semibold.ttf`, `_medium.ttf` | Barlow Condensed — `ofl/barlowcondensed/` | SIL OFL 1.1, [OFL_barlow_condensed.txt](OFL_barlow_condensed.txt) |
| `inter_variable.ttf` | Inter (variable `opsz,wght`) — `ofl/inter/` | SIL OFL 1.1, [OFL_inter.txt](OFL_inter.txt) |
| `jetbrains_mono_variable.ttf` | JetBrains Mono (variable `wght`) — `ofl/jetbrainsmono/` | SIL OFL 1.1, [OFL_jetbrains_mono.txt](OFL_jetbrains_mono.txt) |
| `cinzel_variable.ttf` | Cinzel (variable `wght`) — `ofl/cinzel/` | SIL OFL 1.1, [OFL_cinzel.txt](OFL_cinzel.txt) |

Roles: Barlow Condensed for titles and menu entries, Inter for interface text,
JetBrains Mono for metadata, timestamps and IDs. Cinzel (Bold, tracked out through
`game/rooms/office/poster_title_font.tres`) titles the framed culture prints in the office. The shared theme and weight variations
are generated by `tools/build_ui_theme.gd` into `game/ui/`. The OFL requires the license
to accompany redistributed fonts; it is reproduced in `THIRD_PARTY_NOTICES.txt`.
